# رایان بارای — فرانت مستقل متصل به وردپرس

نسخه ۹ وب‌سایت با Next.js، TypeScript، RTL و خروجی استاتیک قابل استقرار روی cPanel، Apache، Nginx و سرویس‌های میزبانی فایل استاتیک.

## معماری محتوا

وردپرس فعلی پنل درج و ویرایش خبر است. فرمان همگام‌سازی، نوشته‌های منتشرشده، دسته‌بندی، نویسنده و تصویر شاخص را از REST API دریافت می‌کند، تصاویر را داخل پروژه ذخیره می‌کند و یک Snapshot قابل بازیابی می‌سازد. سپس Next.js صفحات HTML، Metadata، Article Schema و Sitemap را تولید می‌کند.

اگر وردپرس هنگام Build در دسترس نباشد، Snapshot قبلی حفظ می‌شود. مقالات تخصصی تحریریه بارای نیز در کنار خبرهای وردپرس نمایش داده می‌شوند تا بخش هوش مصنوعی و حقوقی همیشه محتوای پایه معتبر و تصویر استاندارد داشته باشد.

## راه‌اندازی

```bash
cp .env.example .env.local
npm ci
npm run test:wordpress
npm run build:wordpress
```

خروجی نهایی داخل پوشه `out` است. محتوای این پوشه را داخل `public_html` هاست بارگذاری کنید؛ خود پروژه و `node_modules` نباید در مسیر عمومی کپی شوند.

## انتشار خبر جدید

1. همکار وارد پنل وردپرس می‌شود.
2. نوشته، خلاصه، دسته‌بندی و تصویر شاخص را تکمیل و منتشر می‌کند.
3. مدیر استقرار `npm run build:wordpress` را اجرا می‌کند.
4. محتوای جدید پوشه `out` روی هاست جایگزین می‌شود.

برای انتشار خودکار می‌توان همین فرمان را با Cron/اسکریپت استقرار روی هاست Node‌دار یا Webhook سرویس استقرار اجرا کرد. فرانت عمومی به PHP یا Node وابسته نیست.

## فرمان‌های کنترل

- `npm run content:sync`: همگام‌سازی با امکان استفاده از Snapshot قبلی هنگام قطعی
- `npm run content:sync:strict`: توقف با خطا اگر وردپرس در دسترس نباشد
- `npm run typecheck`: کنترل TypeScript
- `npm run build`: ساخت خروجی استاتیک از Snapshot موجود
- `npm run audit`: کنترل SEO و لینک‌های خروجی
- `npm run build:wordpress`: اجرای کامل همگام‌سازی سخت‌گیرانه، Build و ممیزی
- `npm run test:wordpress`: تست اتصال با دو خبر و دو تصویر روی وردپرس شبیه‌سازی‌شده

جزئیات استقرار و تقسیم محتوا در `WORDPRESS-DEPLOY-FA.md` آمده است.
